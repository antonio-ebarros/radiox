# Security / Segurança

## Scope / Escopo

**EN:** Radio X is designed for a trusted home network. It has no user accounts and no HTTPS, and the PIN for private folders is only a "nosy person" filter. Do not expose it directly to the internet; use a VPN such as Tailscale or WireGuard. See the *Security notice* in the [README](README.md#security-notice).

**PT:** O Radio X foi feito para uma rede doméstica confiável. Não tem contas de usuário nem HTTPS, e o PIN das pastas privadas é só um filtro anti curioso. Não exponha direto na internet; use uma VPN como Tailscale ou WireGuard. Veja o *Aviso de segurança* no [README](README.pt-BR.md#aviso-de-segurança).

## Reporting a vulnerability / Relatando uma vulnerabilidade

**EN:** Please use GitHub's private reporting (repository **Security** tab → *Report a vulnerability*) instead of a public issue. Issues that need the app to be exposed to the internet are known limitations, not vulnerabilities.

**PT:** Use o relato privado do GitHub (aba **Security** do repositório → *Report a vulnerability*) em vez de uma issue pública. Problemas que dependem de expor o app à internet são limitações conhecidas, não vulnerabilidades.
